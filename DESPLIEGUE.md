# Despliegue

Cloudflare Pages publica este repositorio en
https://incomlec-proyecto.pages.dev/ con cada push a `main`.

Para que eso funcione, la app de GitHub «Cloudflare Workers and Pages»
tiene que tener a `Incomlec-proyecto` en su lista de repositorios
(github.com/settings/installations). Si el panel de Cloudflare dice
«Este proyecto está desconectado de tu cuenta de Git» y los push dejan
de desplegarse, es eso: el repo se salió de la lista.
